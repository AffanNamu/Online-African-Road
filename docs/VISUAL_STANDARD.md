# Visual standard and quality gate

Target: realistic, physically grounded West African transport simulation (direction: dark premium UI,
cinematic lighting, believable Lagos/Ibadan environments). Reference image is direction, not to be copied.

## What the code already provides (the pipeline that real art plugs into)
- `VehicleRig` + `VehicleLights`: any production truck/bus prefab with wheel colliders, emitters and lights works
  with the driving code unchanged (`VehicleDefinition.visualPrefab`). Placeholder fallback logs a warning.
- `TimeOfDay`: sun/sky/ambient/fog from live West Africa Time. `WeatherSystem`: rain particles, wet road materials
  (darker + glossier), overcast, grip loss.
- `FollowCamera`: chase/cockpit, speed FOV, restrained shake, brake/accel pitch, zoom.
- `EngineAudio`: RPM-driven synth until recorded loops exist.
- `ChunkStreamer`: budgeted async chunk build, pooled props, data-driven `RouteDefinition`.

## Art that must be sourced/authored (cannot be generated by code)
| Asset | Spec |
|---|---|
| Truck + trailer, bus, minibus ("danfo"), taxi, okada, sedan | PBR (albedo/normal/MRAO), 3 LODs, interior for hero vehicles, VehicleRig set up |
| Road kit | Tiling asphalt/concrete/dirt with detail normals, edge/wear/pothole decals, markings, curbs, medians, barriers, drainage, bridges, ramps |
| Roadside | Nigerian shopfronts, unfinished buildings, motor parks, fuel stations, markets, billboards, poles/wires, street lights, signs |
| Nature | Palms, mango/neem, scrub, farmland, laterite soil; terrain blending |
| People | Pedestrians, vendors (LOD/instanced) |
| Audio | Engine loops (idle/low/high, on/off load), gearbox, tyres, suspension, horn, indicators, rain, ambience |
Licence for every third-party asset must be recorded in `docs/ASSET_LICENSES.md` before it is committed.

## Quality gate (must pass before a visual system is called complete)
1 realistic? 2 physically believable? 3 commercial-grade? 4 authentically African? 5 not placeholder? 6 performs?
7 scales to a larger world? 8 works on Web/Android/iOS? 9 consistent with the rest?
