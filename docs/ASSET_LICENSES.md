# Third-party asset licences

Every third-party file in this repository is listed here with its licence **before** it is committed (`docs/ASSET_PIPELINE.md`, `docs/VISUAL_STANDARD.md`).
This repository is **public**: only assets whose licence allows redistribution may be committed (CC0, MIT, SIL OFL and similar). Paid or commercial assets are never committed here; see
"Licensed assets (Phase 0)" below.

## Rules
1. **CC0** (public domain dedication) needs no attribution, but the source and the date are recorded here so the claim can be checked later.
2. **Attribution licences** (CC-BY, MIT, OFL, ODbL) keep the licence text next to the files and are listed here with the exact attribution wording.
3. **Share-alike licences** (CC-BY-SA, ODbL data, GPL) are not used for game assets or code without an explicit decision by the project owner.
4. Never rely on a seller's or site's statement alone: record the page address, the licence name and version, and the download date. Re-check when updating an asset.
5. Nothing here is a secret. Keys, tokens and licence *keys* are never committed (`tools/check_repo_safety.py` fails the build if one is).

## Licensed assets (Phase 0): recommended approach, not yet adopted
Needs the owner's decision (nothing below has been done):
1. **Keep this repository public, keep paid assets out of it.** Put licensed models and textures in a **separate private repository**, added to the game as a **Git submodule** at `Assets/ThirdParty/` (already ignored by `.gitignore`, and already refused by the repository safety check if it is ever tracked here).
2. CI fetches the private repository with a **read-only deploy key or fine-grained token stored as a GitHub Actions secret** (never in the repository, never printed). Forks and pull requests from outside get no secret, so they build with the placeholders.
3. **The build must work without the private assets** (the placeholder vehicles stay as the fallback), so a missing secret never breaks CI and a reviewer without access can still run the game.
4. The compiled WebGL build contains the assets, which is normally permitted by asset licences (raw files must not be redistributed). Check each licence for "game use", WebGL and redistribution of built products, and keep the receipt id in the private repository.
5. Alternative: make this repository private. That is simpler but changes how contributors, CI artifacts and the `ci-screenshots` branches are shared; it is the owner's call and has not been done.
