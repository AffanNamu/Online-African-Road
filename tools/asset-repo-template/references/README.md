# References

* `REFERENCE_REGISTER.md` is the provenance and usage-rights register (a mirror of the game repository's `docs/kano/REFERENCE_REGISTER.md`). **Metadata only.**
* A reference image is stored here only if its register entry says private reference is allowed AND the owner agreed to store it. Even then it goes in `restricted/` and is never exported.
* Generated concept images must be labelled **CONCEPT: not a photograph of an actual Kano location**.
* Never trace or copy a protected image into a texture, decal or model.
